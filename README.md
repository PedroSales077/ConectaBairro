# Destino Certo

MVP desenvolvido como parte da Experiência Prática III da disciplina de Projeto de Software.

## Sobre o projeto

O Destino Certo é uma aplicação web voltada aos moradores da Vila Curuçá, em São Paulo, com o objetivo de facilitar a consulta de ecopontos e o registro de ocorrências de descarte irregular de resíduos.

## Funcionalidades

- Consulta de ecopontos ativos.
- Visualização de endereço, horário de funcionamento e materiais aceitos.
- Registro de ocorrências com descrição, endereço e fotografia.
- Área administrativa para consulta e atualização do status das ocorrências.

## Tecnologias

- Python 3.12
- Django 5.2 LTS
- Bootstrap 5.3
- SQLite
- Git e GitHub

## Situação do projeto

Em desenvolvimento.

## Objetivo acadêmico

Aplicar conceitos de desenvolvimento web, arquitetura de software, controle de versão, testes automatizados, integração contínua e validação com representantes da comunidade.
